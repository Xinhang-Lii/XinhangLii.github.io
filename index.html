Streaming EchoX

Always listening · semantic check · full-duplex

A simple demo of our streaming full-duplex speech model. The system is still being iterated and improved, and we plan to open-source it in the future.

Overview

Streaming EchoX uses separate listening and speaking streams. The listening stream remains active, while a semantic controller decides when the model should speak, stop, or continue. The model directly generates speech tokens for streaming response.

This page presents a simple research demo. The model is still under active development and will be continuously upgraded. We plan to release the code and model in the future.

Semantic Control

HOLD
The user has not finished speaking.
SPEAK
The user input is complete and answerable.
STOP
A new user intent interrupts the current response.
CONTINUE
A short backchannel does not interrupt the response.

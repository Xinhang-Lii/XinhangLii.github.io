# Streaming EchoX — Bulma Minimal Page

This version uses Bulma from a CDN while keeping the page minimal.

## Add videos

Place these files in `static/videos/`:

- `demo-1.mp4`
- `demo-2.mp4`
- `demo-3.mp4`
- `demo-4.mp4`

## Preview

Double-click `index.html`.

Keep an internet connection when previewing, because Bulma and the fonts are
loaded from online CDNs.
